# NOVA Core API Contracts & Interfaces

This document specifies the public API contracts of NOVA's core modules for future autonomous agent integration.

---

## 1. Multi-Provider AI Brain (`providers.provider_manager`)

### `ProviderManager`
Central gateway managing provider lifecycle, health, failover, and request dispatch.

```python
class ProviderManager:
    def initialize(self) -> None:
        """Constructs and initializes default providers (Gemini, Groq, OpenRouter, Cerebras)."""

    def generate_response(
        self,
        prompt: str,
        system_prompt: str | None = None,
        task_type: TaskType = TaskType.GENERAL,
        mode: Literal["auto", "manual"] = "auto",
        provider_name: str | None = None,
        max_tokens: int | None = None,
    ) -> str:
        """
        Generate a non-streaming text response.
        
        Args:
            prompt: User text input.
            system_prompt: Optional instructions shaping the model's behavior.
            task_type: TaskType (CODING, REASONING, FAST, CHEAP, GENERAL).
            mode: "auto" selects optimal provider; "manual" enforces provider_name.
            provider_name: Required if mode="manual".
            max_tokens: Optional token generation budget.
            
        Returns:
            Clean text string generated by the selected model.
            
        Raises:
            AllProvidersFailedError: If every eligible provider fails or is unreachable.
        """

    def stream_response(
        self,
        prompt: str,
        system_prompt: str | None = None,
        task_type: TaskType = TaskType.GENERAL,
        mode: Literal["auto", "manual"] = "auto",
        provider_name: str | None = None,
    ) -> Iterator[str]:
        """Yields text chunks as they arrive from the active provider."""

    def shutdown(self) -> None:
        """Gracefully terminates underlying client sessions."""
```

## 2. Memory System (`memory.memory_manager`)

### `MemoryManager`
Atomic JSON-backed persistent memory store.

```python
class MemoryManager:
    def add_memory(
        self,
        category: MemoryCategory,
        key: str,
        value: Any,
        importance: int = 3,
        tags: Sequence[str] = (),
    ) -> MemoryEntry:
        """
        Persists a new memory entry atomically.
        
        Args:
            category: MemoryCategory enum (PROFILE, PREFERENCES, PROJECTS, CODING, etc.)
            key: Semantic descriptor label.
            value: JSON-serializable Python object or string.
            importance: Integer scale from 1 (lowest) to 5 (highest).
            tags: Sequence of classification strings.
            
        Returns:
            Immutable MemoryEntry instance with generated ID and timestamps.
        """

    def search_memory(
        self,
        query: str,
        category: MemoryCategory | None = None,
        tags: Sequence[str] | None = None,
        min_importance: int = 1,
        exact_key: bool = False,
    ) -> list[MemoryEntry]:
        """Searches existing memories matching text, category, or tags."""

    def delete_memory(self, memory_id: str) -> bool:
        """Deletes a memory entry by ID. Returns True if deleted."""

    def shutdown(self) -> None:
        """Flushes memory store to disk and shuts down."""
```

## 3. Autonomous Task Agent (`core.task_agent`)

### `TaskPlanner`
Decomposes high-level natural language goals into structured execution plans.

```python
class TaskPlanner:
    def plan_goal(self, goal_text: str, context: TaskContext | None = None) -> TaskPlan:
        """
        Decomposes a goal into an ordered sequence of TaskSteps.
        
        Args:
            goal_text: High-level user goal (e.g. "Create a project folder and search for tutorials")
            context: Optional active TaskContext.
            
        Returns:
            TaskPlan containing goal description, estimated risk, and TaskStep list.
        """
```

### `TaskExecutor`
Executes multi-step task plans with step-level verification and recovery.

```python
class TaskExecutor:
    def execute_plan(self, plan: TaskPlan, context: TaskContext | None = None) -> TaskResult:
        """
        Executes a TaskPlan step-by-step.
        
        Returns:
            TaskResult with overall status (SUCCESS, FAILED, CANCELLED), execution time, and message.
        """

    def cancel_task(self) -> None:
        """Sets internal cancellation flag, terminating active plan execution."""

    def reset_cancellation(self) -> None:
        """Resets cancellation event before starting a new task."""
```

### `CapabilityRegistry`
Registers verified executable tools.

```python
class CapabilityRegistry:
    def register(self, cap: CapabilityDefinition) -> None:
        """Registers a CapabilityDefinition with handler, verifier, and risk rating."""

    def get(self, name: str) -> CapabilityDefinition | None:
        """Retrieves a capability by unique name (e.g. 'fs.create_folder')."""
```

## 4. Computer Interaction & Vision (`core.computer_agent`, `core.eyes`)

Coordinates visual goal perception and execution (`SEE -> UNDERSTAND -> PLAN -> ACT -> VERIFY`).

```python
class ComputerAgent:
    def execute_visual_goal(self, goal_text: str, action_hint: str | None = None) -> VisualResult:
        """Locates on-screen UI element matching goal_text and performs action."""

    def type_into_focused_or_target(
        self,
        text: str,
        target_label: str | None = None,
        submit: bool = False,
    ) -> VisualResult:
        """Types text into the active cursor focus or targeted UI input field."""

    def close_popup(self) -> VisualResult:
        """Locates and dismisses active modal popups, cookie prompts, or alerts."""

    def scroll_until_visible(self, target_text: str, max_scrolls: int = 5) -> VisualResult:
        """Repeatedly scrolls the active viewport until target text is visible in OCR."""

    def stop_active_task(self) -> bool:
```

Deterministic resolver for deictic natural references.

```python
class ContextResolver:
    @classmethod
    def resolve_target(
        cls,
        reference_term: str,
        context: EnvironmentContext,
        target_type: str = "any",
    ) -> dict[str, Any]:
        """
        Resolves "this", "that", "the selected file", "the current tab" to a concrete Path or URL.
        
        Returns:
            dict with keys: 'resolved' (bool), 'target' (Path | str | None), 'target_type' (str).
        """
```

```python
class EventBus:

        """Registers an event listener for a NovaEvent."""

    def publish(self, event: NovaEvent, **payload: Any) -> None:
        """Publishes an event to all registered subscribers safely."""
```
